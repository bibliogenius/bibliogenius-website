Puedes conectar con otros lectores de dos maneras: escaneando un código QR o compartiendo un enlace de invitación.

## Por código QR (en persona)

1. Abre la sección Red
2. Pulsa "Conectar una biblioteca"
3. Muestra tu código QR a la otra persona, o escanea el suyo
4. Una vez conectados, cada uno puede consultar el catálogo del otro

Es el método más sencillo cuando estáis en el mismo sitio.

## Por enlace de invitación (a distancia)

También puedes enviar un enlace de invitación por mensajería, correo o cualquier otro canal:

1. Abre la sección Red
2. Pulsa "Compartir un enlace de invitación"
3. Envía el enlace a tu amigo por tu mensajería preferida
4. Al abrir el enlace, BiblioGenius se abre y le propone aceptar la conexión

El enlace contiene lo necesario para establecer la conexión, incluidas las claves de cifrado.

## Una conexión segura

La conexión entre bibliotecas está cifrada de extremo a extremo, sea cual sea el método. Tus contactos solo ven los libros que decides compartir.
