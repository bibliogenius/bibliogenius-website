Sie können sich auf zwei Wegen mit anderen Lesenden verbinden: über einen QR-Code oder über einen Einladungslink.

## Per QR-Code (vor Ort)

1. Öffnen Sie den Bereich Netzwerk
2. Tippen Sie auf "Eine Bibliothek verbinden"
3. Zeigen Sie Ihren QR-Code, oder scannen Sie den der anderen Person
4. Sobald die Verbindung steht, kann jeder den Katalog des anderen durchsehen

Das ist der einfachste Weg, wenn Sie am selben Ort sind.

## Per Einladungslink (aus der Ferne)

Sie können auch einen Einladungslink über Messenger, E-Mail oder einen beliebigen anderen Kanal schicken:

1. Öffnen Sie den Bereich Netzwerk
2. Tippen Sie auf "Einladungslink teilen"
3. Schicken Sie den Link über Ihren bevorzugten Messenger
4. Beim Öffnen des Links startet BiblioGenius und bietet an, die Verbindung anzunehmen

Der Link enthält alles, was für die Verbindung nötig ist, einschließlich der Schlüssel für die Verschlüsselung.

## Eine sichere Verbindung

Die Verbindung zwischen Bibliotheken ist Ende-zu-Ende verschlüsselt, unabhängig vom gewählten Weg. Ihre Kontakte sehen nur die Bücher, die Sie zum Teilen freigeben.
