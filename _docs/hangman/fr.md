Le Pendu prend les titres de votre propre bibliothèque comme grille de jeu : à vous de retrouver le titre caché, lettre par lettre.

## Lancer une partie

Le jeu vit dans la section Jeux. S'il n'apparaît pas, activez-le dans les Paramètres : les jeux sont des modules optionnels, chacun s'active ou se désactive séparément.

## Le principe

Un titre de votre bibliothèque est tiré au sort et masqué. Vous proposez des lettres : les bonnes se placent dans le titre, les mauvaises font avancer le dessin. À vous de terminer le mot avant le dessin.

Comme les titres viennent de vos propres livres, la difficulté suit votre bibliothèque : plus elle grandit, plus les parties se renouvellent.
